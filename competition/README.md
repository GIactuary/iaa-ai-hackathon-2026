# Competition files

Drop here, as markdown or text, copied from the Kaggle pages when the competition opens:

- `overview.md`: the overview page, including the judging criteria and any weights
- `rules.md`: the full rules (external data, AI tools, team, submission)
- `evaluation.md`: the metric and submission format
- `data_description.txt` or similar, if provided

Then run `/intake` in Claude Code. It writes `brief.md` here.
